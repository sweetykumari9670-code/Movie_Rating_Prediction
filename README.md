

## Project Overview
This project predicts movie ratings using machine learning techniques in Python.

## Task
Movie Rating Prediction with Python

## Dataset
IMDb Movies India dataset

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Google Colab

## Machine Learning Model
Linear Regression

## Project Steps
1. Data loading
2. Data cleaning and preprocessing
3. Feature engineering
4. Encoding categorical features
5. Train-test split
6. Model training
7. Model evaluation
8. Movie rating prediction

## Result
The Linear Regression model was trained to predict movie ratings based on the selected movie features.
